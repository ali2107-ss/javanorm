# Руководство пользователя

## Назначение

«НормаКонтроль» помогает загрузить документ, проверить его по правилам ГОСТ, увидеть нарушения, скачать отчёт и получить исправленную DOCX-версию.

## Вход

1. Откройте `http://localhost:8080`.
2. Введите email и пароль.
3. Для демонстрации можно использовать `admin@demo.ru / Admin1234!`.

## Проверка документа

1. Перейдите в раздел документов или проверки.
2. Загрузите файл DOCX, PDF, TXT или MD размером до 50 МБ.
3. Нажмите запуск проверки.
4. Дождитесь статуса `CHECKED`.
5. Откройте результат проверки.

## Работа с отчётами

Доступны форматы:

- PDF: `GET /api/v1/documents/{id}/report/download`;
- HTML: `GET /api/v1/documents/{id}/report/html`;
- JSON: `GET /api/v1/documents/{id}/report/json`.

Отчёт содержит итоговый балл, список нарушений, критичность, место нарушения, рекомендацию и код правила.

## Автоисправление

Для DOCX-документа можно запустить автоисправление через кнопку в интерфейсе или endpoint:

```text
POST /api/v1/documents/{id}/fix
```

Исправленный файл скачивается с именем исходного документа.

## История и фильтры

Список документов поддерживает фильтрацию:

```text
GET /api/v1/documents?status=CHECKED&type=docx&createdFrom=2026-05-01&createdTo=2026-05-04
```

История проверок:

```text
GET /api/v1/check-results/document/{documentId}/history
```

## Профиль и GDPR

Профиль:

```text
GET /api/v1/users/me
PATCH /api/v1/users/me
```

Экспорт персональных данных:

```text
GET /api/v1/users/me/export
```

Удаление аккаунта с анонимизацией:

```text
DELETE /api/v1/users/me
```
